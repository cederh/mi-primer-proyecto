# Mi primer proyecto

Este proyecto es una página web básica creada para aprender los fundamentos del control de versiones con Git y GitHub. Contiene una estructura inicial en HTML con metas y temas de aprendizaje sobre desarrollo web.

## Tecnologías utilizadas

- **HTML5**: Estructura del documento web.
- **Git y GitHub**: Control de versiones y gestión del repositorio.

## Instrucciones para abrir el proyecto

1. Clona el repositorio o descarga los archivos del proyecto en tu equipo:
   ```bash
   git clone <URL-del-repositorio>
   ```
2. Dirígete a la carpeta del proyecto:
   ```bash
   cd mi-primer-proyecto
   ```
3. Abre el archivo `index.html` en tu navegador web preferido haciendo doble clic sobre él o ejecutando:
   - En Windows: `start index.html`
